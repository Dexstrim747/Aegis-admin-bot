Политика конфиденциальности Aegis

Дата обновления: 03.08.2026

1. Общая информация

Aegis — Telegram-бот, предназначенный для управления, администрирования и автоматизации процессов внутри Telegram-чатов.

Используя Aegis, пользователь соглашается с условиями настоящей политики конфиденциальности.

2. Какие данные собираются

Aegis может обрабатывать следующие данные:

Данные Telegram-профиля:
Telegram ID пользователя;
имя пользователя (username);
имя профиля (first name).
Данные чатов:
Telegram ID чата;
название чата;
настройки, связанные с работой бота.
Технические данные:
дата и время взаимодействия с ботом;
информация о выполненных командах;
технические журналы работы (логи).
3. Цель обработки данных

Данные используются исключительно для:

идентификации пользователей;
работы функций бота;
хранения настроек;
обеспечения безопасности;
диагностики ошибок;
улучшения стабильности работы.
4. Хранение данных

Данные хранятся в базе данных Aegis.

Aegis не продаёт, не передаёт и не публикует пользовательские данные третьим лицам.

5. Удаление данных

Пользователь может запросить удаление своих данных.

Для этого необходимо обратиться к владельцу бота через контакт, указанный в профиле Aegis.

После подтверждения запроса связанные данные будут удалены, если их хранение не требуется для обеспечения безопасности или работы системы.

6. Безопасность

Aegis принимает разумные меры для защиты данных:

ограничение доступа к базе данных;
защита токена Telegram Bot API;
контроль прав доступа;
ведение технических журналов.

Однако ни один способ хранения данных не может гарантировать абсолютную безопасность.

7. Telegram API

Aegis использует Telegram Bot API.

Обработка данных также регулируется правилами Telegram.
